# Subscrap 유사 서비스·우수 관행 분석

기준일: 2026-08-20 UTC  
범위: 현재 프로젝트 파일, 공개 앱, 기존 자동 검사, 공개 비교 서비스의 공식 웹·공식 앱 마켓·공식 도움말. 제품 코드·설정·의존성·배포·저장 기록·보관소 업로드는 변경하지 않았다.

## 1. 대상 서비스 한 문단 설명

Subscrap은 개인이 직접 적은 구독과 사용자가 허용한 Gmail·Google Play 자료에서 찾은 후보를 한곳에 모아, 월 지출·다음 결제일·절약 기회·공식 해지 안내를 이해하도록 돕는 설치형 웹앱(PWA)이다. 자동 탐지는 확정이 아니라 검토 시작점이며, 후보의 출처·이유·금액·날짜·신뢰도를 보여 주고 사용자가 직접 등록하거나 무시할 수 있게 설계돼 있다.

## 2. 자동 분류

| 구분 | 내장 500개 카탈로그 | 적합도 | 선택 근거 | 확신도 |
|---|---:|---:|---|---|
| 주 도메인 | 15 개인 자산관리 | 90/100 | 반복 지출을 모아 이해·절약 행동을 돕는다 | 높음 |
| 보조 | 16 예산 관리 | 78/100 | 월 합계·결제일·절약 기회를 제공한다 | 높음 |
| 보조 | 10 구독 상거래 | 71/100 | 구독을 판매하지는 않지만 외부 구독을 추적·관리한다 | 보통 |
| 보조 | 76 일정·캘린더 | 55/100 | 결제일 달력이 보조 핵심 흐름이다 | 높음 |

점수는 내부 정렬용 적합도이며 시장 규모나 사업 성과를 뜻하지 않는다.

## 3. 실제 확인된 기능

- 직접 구독 등록·수정, 검색·필터·정렬, 다통화, 월 합계·다음 결제일·달력·절약 기회
- Gmail과 Google Play를 분리해 동의받는 후보 탐지, 계정 격리, 원문 미보관, 연결 해제 정리
- 후보의 출처·탐지 사유·금액·날짜·신뢰도 표시와 직접 등록·무시
- 공식 해지 안내, 백업·복원·내보내기, 한국어·영어, PWA 오프라인 처리
- 로컬 자동 검사 336/336, 접근성 8화면 심각 위반 0, 가상 사용자 1,000명·구독 8,136건 불변식 위반 0

공개 앱은 v0.21.2이며 v0.21.3 화면 후보는 PR #9에 있다. Cloud Run 운영 API는 v0.21.3이지만 Pages 반영은 별도 상태다.

## 7. 예비 수준 점수와 증거 완성도

Readiness Hub core v2.1.0, 197개 기준을 실행했다. 복합 점수는 **40.93**, 모바일 **47.92**, 웹 **49.13**이다. 그러나 채워진 증거가 모바일 4%, 웹 6%라 엔진 등급은 둘 다 **판정 보류(L2?, 낮은 신뢰도)** 이다. 이 수치는 ‘실패 점수’가 아니라 대다수 운영·법률·결제·성능 항목을 아직 증거로 평가하지 않았다는 계산 결과다.

## 8. 강점 3개

1. 자동 탐지를 확정으로 포장하지 않고 후보 근거·직접 등록·무시로 사용자 판단을 보존한다.
2. Gmail·Google Play 권한을 분리하고 원문 미보관·사용자 격리·연결 해제 정리를 검사한다.
3. 앱·서버·파서·오프라인·해지 감시를 합친 336개 자동 검사와 접근성·가상 사용자 근거가 있다.

## 10. 경쟁력 기준 갭

- 사용자가 무시·확정·직접 등록한 이유를 집계해 탐지 품질을 개선하는 폐쇄 고리
- 계정별 탐색 시각·성공·실패·범위의 설명 가능한 상태
- 알림별 이유·시점·빈도 설정과 수신 성공률
- 서비스·결제 주체별 해지 확인 안내
- 공개 후 되돌리기 기준과 단계적 공개

## 11. 차별화 기회

Subscrap은 은행 계정 전체를 연결하지 않고도 Gmail·Google Play의 제한된 자료와 직접 등록을 함께 쓸 수 있다. 이 장점은 ‘모든 결제를 찾는다’는 과장 대신, **무엇을 확인했고 무엇을 확인하지 않았는지 설명하는 구독 관리**로 포지셔닝할 때 가장 강하다.

## 15. Android 실기기 시험 상태

유휴 A56 `R5CY32TNJFM`은 ADB `device`, SM-A5660, 720×1560으로 확인됐다. 그러나 Chrome으로 공개 URL을 여는 명령은 이 실행 환경의 보안 정책이 거절했다. 따라서 실제 화면·온보딩·설치·로그인·구독 데이터 변경은 **미실시**다. 두 번째 폰은 조작하지 않았다.

엔진·렌즈·예제는 프로젝트 안에 없어서 분석 폴더 `engine/`에만 공개본을 받았다. 실행은 성공했고 `readiness-analysis.json`과 `readiness-analysis.md`를 만들었다. 엔진은 범용 상용 서비스 기준이므로, 스토어 심사·광고·UGC·결제 등 Subscrap의 현재 범위 밖 또는 미확인 항목을 다수 포함한다. 이 때문에 이 점수만으로 상용화 완료·법적 준수·시장 성과를 판단할 수 없다.
