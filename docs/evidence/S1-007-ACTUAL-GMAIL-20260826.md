# S1-007 실제 Gmail 운영 검증 — 2026-08-26

## 판정

`PARTIAL` — 실제 Gmail 읽기 전용 탐색과 동일 계정 재탐색 중복 방지는 통과했다. Google Play 별도 권한, 결과가 0개인 계정, 실제 다계정 격리, 연결 해제·서버 삭제는 아직 실제 증거가 없어 전체 PASS로 올리지 않는다.

## 환경

- 공개 웹: `v0.27.3`
- 운영 API: `v0.27.3`
- 실행 경로: 공개 앱의 `내 유료서비스 자동으로 찾기` → `Gmail·Google Play` → 이미 연결된 승인 계정의 `Gmail 찾기`
- 권한 경계: Gmail 읽기 전용 연결만 사용했다. Google Play Data Portability 권한은 요청하지 않았다.
- 개인정보 경계: 계정 주소, 메일 제목·본문, 실제 서비스명, 금액, 토큰을 이 문서와 GitHub에 기록하지 않았다.

1. Google Play 구독·구매 자료의 별도 OAuth 동의와 실제 내보내기
2. 결과 0개 계정에서 오해 없는 빈 결과 문구
