개인정보 처리방침 공개후보

갱신일 2026-08-30 · 공개후보 v0.36 · 실제 사업자·책임자·처리국가 값은 전문가 검토 전까지 허위로 채우지 않습니다.

처리하는 자료

기기에는 직접 입력한 구독·설정·검토 상태를 저장합니다. Google 연결 시 허용된 Gmail·Play 분석 결과와 암호화된 접근 열쇠를 처리합니다. 이메일·계정 표시값 같은 직접 식별정보는 서버 저장 전에 AES-256-GCM으로 암호화하고, 이메일 찾기에는 별도의 되돌릴 수 없는 검색 지문을 사용합니다. 문의 진단정보는 별도 동의한 경우에만 앱 판·운영체제·브라우저·언어·시간대·온라인 상태·화면 크기의 허용목록을 저장합니다. 환율은 Subscrap 서버가 받아 전달합니다.

처리하지 않는 자료

Gmail 원문, Apple 비밀번호, 카드 번호와 지원 첨부 원문은 저장하지 않습니다. 첨부는 이름·종류·크기·지문값만 남깁니다. 자료를 광고·신용·보험·고용평가·데이터 판매에 사용하지 않습니다.

목적·보관·삭제

계정·보안, 구독 후보 탐지, 기기 간 합치기, 문의 처리, 보안·장애 대응의 선언된 목적에만 사용합니다. 서버 저장은 이 여섯 목적 중 하나를 코드로 지정하지 않으면 거절됩니다. Gmail과 Play 동의는 따로 기록하고 미동의 시 탐색을 거절합니다. 동의 철회 시 해당 통로의 접근 열쇠와 미확정 근거를 함께 삭제하고 다른 통로와 직접 확정한 구독은 유지합니다. 로그인 임시자료는 5~10분, 거절 후보는 30일, 중복 방지 지문은 최대 90일 뒤 자동 정리합니다. 서버 계정 삭제는 7일 대기하며 그 전까지 취소·내보내기가 가능합니다.

사용자의 권리

개인정보 화면에서 저장 수량·동의·최근 90일 사람 열람 횟수를 확인하고, 동의 철회·서버 JSON 내보내기·계정 삭제를 직접 시작할 수 있습니다. 사람의 지원 확인은 사용자가 문의별 자료 범위와 최대 60분을 허용하고 서로 다른 담당자 2명이 승인해야 하며, 사용자는 즉시 철회할 수 있습니다. Gmail 원문과 접근 열쇠는 이 지원 통로로 제공되지 않습니다. 진단정보 동의를 거부해도 일반 문의를 보낼 수 있습니다.

Google API 자료의 Limited Use

Google Workspace API에서 받은 정보의 사용은 Google API Services User Data Policy를 준수하며 Limited Use 요구사항을 포함합니다. Google 자료는 사용자가 선택한 유료서비스 후보 탐색과 계정 기능에만 사용하고 광고·일반 AI 모델 학습·신용·고용·보험 결정·자료 판매에 사용하지 않습니다. 사용자가 동의를 철회하거나 연결을 삭제하면 해당 통로의 인증정보와 미확정 자료를 삭제합니다.

공개 콘텐츠와 광고의 분리

광고는 로그인 없이 읽는 공개 가이드에서만 표시할 수 있고 개인 구독 앱은 항상 무광고입니다. Gmail·Google Play·영수증·결제 표·Apple 구매 파일·탐색 결과·서비스명·금액·갱신일·계정정보와 사용자 판단은 광고 선택·개인화·측정·프로파일링에 제공하지 않습니다. 동의는 기본 거부이며 동의가 필요한 지역에서는 Google 인증 CMP의 유효한 신호가 있을 때만 공개 페이지 광고 로더가 작동합니다. 현재 광고 송출은 비활성화되어 있습니다. 광고 정책 · 쿠키 정책

운영 사업자, 개인정보 보호 책임자, 수탁자, 처리국가별 이전 근거와 법정 보관기간은 실제 운영값 확정 뒤 자격 있는 전문가의 검토를 거쳐야 합니다.
